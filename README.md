# golandia-codigo

El código de los vídeos del canal de YouTube **Golandia**: Go (y las comparativas «¿Go o X?»).

Cada carpeta es un vídeo (o una serie de vídeos que comparten código) y lleva su propio `README.md` con el enlace al vídeo y cómo ejecutarlo. Los archivos `SALIDA*.md` son los resultados reales de la ejecución que sale en pantalla.

Si el vídeo es para **miembros del canal**, la carpeta lo dice en su README y enlaza el vídeo: el código es público para todos, el vídeo lo consiguen los miembros.
