== 1. kcli: arbol de subcomandos anidados (como kubectl) ==
kcli es una CLI de demostracion construida con Cobra y Viper

Usage:
  kcli [command]

Available Commands:
  completion  Generate the autocompletion script for the specified shell
  config      inspecciona la configuracion resuelta
  help        Help about any command
  serve       arranca o detiene el servidor de demostracion

Flags:
      --config string   archivo de configuracion (default ./kcli.yaml)
  -h, --help            help for kcli

Use "kcli [command] --help" for more information about a command.
---
arranca o detiene el servidor de demostracion

Usage:
  kcli serve [command]

Available Commands:
  start       arranca el servidor (demostracion, no abre ningun puerto de verdad)
  stop        detiene el servidor (demostracion)

Flags:
  -h, --help   help for serve

Global Flags:
      --config string   archivo de configuracion (default ./kcli.yaml)

Use "kcli serve [command] --help" for more information about a command.
