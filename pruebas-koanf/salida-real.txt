== 6. VIPER contra KOANF: que expone cada una cuando falla ==
== VIPER, sin SetEnvKeyReplacer ==
  server.host = desde-archivo-config
  lo que expone AllSettings():
    server = map[host:desde-archivo-config port:9000]

== KOANF, sin funcion de transformacion ==
  server.host = desde-archivo-config
  lo que expone All():
    KCLI_SERVER_HOST = desde-entorno
    server.host = desde-archivo-config
    server.port = 9000
